# Day 28: Simple Percentage Analysis

## 📌 Overview
This repository contains the Day 28 Data Analytics task focusing on **Simple Percentage Analysis** as part of the Veda Technology Data Analytics Internship. 

The primary goal of this project is to calculate and analyze the percentage contribution of product categories toward total business sales, ensuring clear reporting and visualization.

---

## 🎯 Objectives
- Summarize raw transactional data into high-level business categories.
- Calculate category-wise percentage contribution relative to total sales.
- Create clear data visualizations using pie/donut charts.
- Maintain transparent documentation of denominators and business totals.

---

## 🛠 Tools & Techniques Used
- **Tool:** Microsoft Excel (Online / Desktop)
- **Data Summarization:** Pivot Tables (`SUM` aggregation)
- **Calculations:** Percentage Contribution formula $\left(\frac{\text{Category Sales}}{\text{Grand Total Sales}} \times 100\right)$ using absolute cell references (`$`).
- **Data Visualization:** Pie Chart with custom slice color coding and data labels.

## ❓ Interview Questions & Business Logic

### 1. What does percentage contribution mean?
Percentage contribution represents the proportion or share that a specific category contributes toward the grand total. It helps stakeholders identify top-performing product lines and evaluate their relative impact on total revenue.

### 2. Why must the denominator be stated?
Stating the denominator (Grand Total) provides necessary context for percentage calculations. Without knowing the baseline total, percentages alone can be misleading, as 50% of a $1,000 baseline represents a vastly different business impact than 50% of a $1,000,000 baseline.
