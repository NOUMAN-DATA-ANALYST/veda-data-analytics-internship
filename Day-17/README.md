# Task 17: Monthly Sales Trend Analysis

## Project Overview
This project focuses on analyzing sales data to track monthly revenue patterns and build accurate time-series visual reports. By aggregating sales figures chronologically using Pivot Tables and line visualizations, this task helps identify sales peaks, seasonal drops, and overall performance trends.

## Deliverables
1. **Monthly Aggregation Table**: A Pivot Table aggregating `Total Amount` by `Month` structured in chronological sequence (`Jan-2023` to `Jan-2024`).
2. **Line Visualization**: A line chart titled **"Monthly Sales Trend"** depicting revenue fluctuations across the timeline.

## Key Insights
- **Peak Performance**: May 2023 recorded the highest sales at **$53,150**, followed closely by October 2023 (**$46,580**).
- **Lowest Performance**: January 2024 showed minimal sales activity (**$1,530**), representing the lowest month in the dataset.
- **Total Revenue**: Cumulative revenue across the entire observation period stands at **$456,000**.

## Tech Stack & Tools
- **Microsoft Excel for the Web** (Pivot Tables, Custom Date Formats, Line Charts)
- **Data Analysis & Visualization**
