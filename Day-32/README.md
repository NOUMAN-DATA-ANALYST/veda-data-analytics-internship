# Day 32 Major Project: OTT Streaming Content Trend Analysis (Netflix/Prime/Hotstar)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on an OTT streaming platform catalog dataset to analyze genre popularity, content ratings, release trends, and regional content distribution over time.

## 🛠️ Tools & Libraries Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Database:** SQL (SQLite)
- **Environment:** Google Colab

## 📊 Key Analysis & Visualizations Included
1. **Content Type Breakdown:** Movies vs TV Shows distribution.
2. **Release Trend:** Yearly content additions from 2000 to present.
3. **Top Genres:** High-demand content categories analysis.
4. **Regional Distribution:** Top content-producing countries.
5. **Rating Demographics:** Age-rating classification across formats.
6. **Movie Runtime:** Runtime distribution in minutes.

## 💡 Content Strategy Memo (Key Insights)
- **Binge-Watching Focus:** Shift acquisition towards multi-season TV Shows to boost long-term subscriber retention.
- **Regional Expansion:** Scale licensing for non-US regions (South Korea, India, UK) due to rapidly rising viewer engagement.
- **Runtime Optimization:** Target feature film durations around ~95 minutes for optimal viewer completion rates.
